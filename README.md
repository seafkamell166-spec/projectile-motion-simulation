# Projectile Motion Simulation (Python & C++)

## Overview
A Classical Mechanics project that simulates two-dimensional projectile motion under constant gravity, comparing several launch angles. It was implemented twice — once in Python (with a full numerical simulation and generated plots) and once in C++ (using the closed-form analytical equations) — to compare a step-by-step numerical approach against the theoretical formulas.

## Features
- Simulates trajectories for launch angles of 20°, 30°, 45°, 60°, and 70° at a fixed initial speed
- Computes range, maximum height, and flight time for each angle, and compares the simulated values against the theoretical (closed-form) values
- Generates a trajectory comparison plot (all angles overlaid) and an energy-conservation plot (kinetic, potential, and total energy over time for the 45° launch)
- Exports a CSV table of the numerical results
- Prints a short written analysis of the results (e.g. complementary angles like 30°/60° producing the same range)

## Technologies Used
- **Python 3** — numerical (Euler-method) simulation, `dataclasses`, and custom plotting with **Pillow (PIL)** (no external plotting library)
- **C++** — a second implementation using the analytical projectile-motion equations directly
- `csv` module for exporting results

## How It Works
- **Python (`python/projectile_simulation.py`):** steps the simulation forward in small time increments (`TIME_STEP = 0.02s`) using Euler integration, interpolating the exact landing point once the projectile crosses `y = 0`. It also computes the theoretical range/height/flight-time from the standard kinematic formulas for comparison, then renders the trajectory and energy plots by drawing directly onto a Pillow canvas (axes, gridlines, and labels are all hand-drawn).
- **C++ (`cpp/projectile_simulation.cpp`):** computes the same launch angles directly from the closed-form equations (no time-stepping), prints a results table, and reports which angle produced the greatest range.

## How to Run

**Python version:**
```bash
pip install pillow
python python/projectile_simulation.py
```
This regenerates the CSV table and PNG plots inside `outputs/`.

**C++ version:**
```bash
g++ cpp/projectile_simulation.cpp -o projectile_sim
./projectile_sim
```

## Known Limitations
- The Python simulation uses simple Euler integration, so its numerical results are very close to — but not perfectly identical to — the C++ version's exact analytical values (a smaller `TIME_STEP` would narrow this further at the cost of runtime).
- Air resistance is not modeled; both versions assume idealized motion under constant gravity only.
